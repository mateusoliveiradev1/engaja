# FLV Visual QA Checklist

Use this checklist before calling a mobile screen ready for release.

- Reject anything that looks like a generic SaaS dashboard, starter social feed or default template.
- Review the first viewport on narrow Android widths and confirm the key action, freshest signal and operational risk are visible.
- Test dynamic text and confirm there is no text overlap, clipping or broken hierarchy.
- Remove nested cards that do not add hierarchy or action clarity.
- Confirm loading, empty, error, offline, permission-denied and success states exist for each primary flow.
- Check contrast, labels and touch targets on shared components before sign-off.
- Verify photo surfaces, evidence thumbnails or produce-inspired color blocks keep the FLV identity visible.
